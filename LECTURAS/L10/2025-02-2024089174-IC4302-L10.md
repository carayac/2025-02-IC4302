### ¿En qué consiste SQL Injection?

Es una forma de ataque en la que el término inyección se refiere a la manipulación de las entradas del usuario a través de una interfaz, aprovechando vulnerabilidades asociadas con la construcción de las consultas SQL. El atacante puede insertar código malicioso dentro de una consulta, logrando que el sistema ejecute instrucciones no previstas. Esto puede permitirle recuperar información no autorizada, eliminar datos, modificarlos o incluso insertar nuevos registros sin el permiso del sistema.
Este tipo de ataque puede comprometer la confidencialidad, integridad, disponibilidad, autenticación y autorización de la base de datos.

### ¿En qué consiste Access Control?

Es el proceso mediante el cual se asegura que los datos o recursos de la base de datos solo puedan ser accedidos de manera autorizada.
El control de acceso se puede representar mediante una matriz de control de acceso, donde las columnas representan los objetos de la base de datos, las filas representan roles, grupos de usuarios o aplicaciones, y las celdas indican el tipo de acceso permitido.
Los tipos de permisos más comunes son: READ, INSERT, UPDATE, DELETE, EXECUTE y CREATE.

### Comente el rol de la Observabilidad en la seguridad de bases de datos

La observabilidad en la seguridad de bases de datos cumple un rol fundamental al permitir el monitoreo continuo de las acciones que se realizan sobre los datos. A través de herramientas como los security logs y los audit trails, los administradores pueden detectar intentos de violación de seguridad, registrar operaciones sospechosas y rastrear quién realizó cada acción, desde qué estación de trabajo y en qué momento exacto.

Estos mecanismos no solo facilitan la detección y respuesta ante incidentes, sino que también actúan como medida preventiva, ya que los usuarios son conscientes de que sus acciones están siendo registradas. Además, permiten identificar actividades malintencionadas incluso de usuarios autorizados, brindando una visión completa del comportamiento dentro del sistema. En conjunto, los registros y auditorías fortalecen la observabilidad del sistema y aumentan la transparencia y trazabilidad en la gestión de la seguridad de la base de datos.

### ¿Cómo se encripta información en una base de datos?

La encriptación se utiliza con el objetivo de que solo el sistema de administración de bases de datos (DBMS) pueda descifrar la información, incluso si esta es robada.
Cuando un usuario autorizado solicita acceder a los datos, el DBMS se encarga de desencriptarlos automáticamente.

El proceso de encriptación requiere un sistema de cifrado (cipher system) compuesto por los siguientes elementos:

1. Algoritmo de encriptación: transforma el texto plano en texto cifrado mediante operaciones matemáticas.

2. Llave de encriptación: se utiliza como parte de la entrada del algoritmo para generar el texto cifrado.

3. Algoritmo de desencriptación: toma el texto cifrado y lo convierte nuevamente en texto plano.

4. Llave de desencriptación: se emplea junto al algoritmo correspondiente para recuperar la información original.
