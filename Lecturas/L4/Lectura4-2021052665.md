¿Qué es la observabilidad? La observabilidad se refiere a la capacidad de un sistema de determinar su calidad o estado viendo los outputs, viendo el front end.  

¿Por qué es importante? Porque en sistemas ya profesionales hay demasiadas partes distintas integradas, es más sencillo  

Métricas: data numérica que mide tiempo para generar estadísticas y cálculos según los datos del sistema.  

Logs y eventos: eventos son los hechos que pasan en la ejecución del sistema, datos que se reciben etc. Y logs es el registro de estos eventos para generar datos a ser analizados.  

Traces: son análisis de un proceso, siendo proceso una acción que tiene inicio y fin en una aplicación como comprar un producto, se registra cada interacción del usuario en el proceso.  

APM: Las siglas significan Application Performance Monitoring, muestra el rendimiento de un sistema sea aplicación o web con distintas métricas y dimensiones.
