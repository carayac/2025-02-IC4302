### ¿En qué consiste SQL Injection?  
Es un ataque, que sucede en contra de las bases de datos.  El término inyección se refiere a que la entrada del usuario desde un cliente puede aprovecharse para generar vulnerabilidades asociadas con la construcción dinámica de consultas SQL. Mediante la inyección SQL, un atacante puede insertar o bien como lo dice el termino, inyectar código en una consulta que puede usarse para recuperar información a la que no está autorizado a acceder, también podría eliminar o modificar esa info incluso hacer inserciones para conseguir acceso a la bd.  

### ¿En qué consiste Access Control?  
Esto consiste en asegurar que solo por autorización se pueda acceder a los datos u otros recursos.  El control de acceso es un componente fundamental para garantizar la confidencialidad y la integridad en una empresa. ### Comente el rol de la Observabilidad en la seguridad de bases de datos  

La observabilidad sirve para ver y entender todo lo que ocurren dentro del sistema, como para ver accesos, cambios o cualquier intento sospechoso a la seguridad del sistema.  Se pueden utilizar security logs que son como un libro donde quedan anotados todos los intentos de violación y pueden generar alertas también.  Para las atacantes, saber de esta herramienta puede evitar que alguien con malas intenciones intente algo. Los Audit trails también son otra herramienta que ayuda a la observabilidad en seguridad ya que guarda quien accedió, que hizo, desde donde, a que hora, que cosas fueron alteradas, todo esto para detectar actividades sospechosas.  En general la observaibilidad es sumamente importante porque permite detectar problemas a tiempo y también identificar responsables en caso de algún problema, sirve como para tener una trazabildiad mucho más robusta.

### ¿Cómo se encripta información en una base de datos?  

La encriptación de info se utiliza para evitar el acceso directo a los datos a través del sistema operativo o que puedan ser robados y su robo, estos se pueden almacenar en la base de datos de forma cifrada.   El mismo sistema descifrar los datos, y solo cuando los usuarios autorizados acceden a la información, el sistema la recupera y la descifra automáticamente.  Al hacer cifrado se deben seguir ciertos pasos o tener distintos componentes:  
-	Debe realizarse un algoritmo de cifrado para convertir texto plano en texto cifrado por medio de operaciones  
-	Debe utilizarse una clave de cifrado que forma parte de la entrada del algoritmo de cifrado.  Esta key debe elegirse de muchas opciones posibles según sea el caso  
-	Así como para cifrar también debe haber un algoritmo de descifrado y que opera sobre el texto ya cifrado y saca el texto plano  
-	Tambien una clave de descifrado que es parte del algoritmo de descifrado y también es elegida de un conjunto amplio de llaves según sea el caso
