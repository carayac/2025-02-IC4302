### 1. ¿Cómo funciona el particionamiento horizontal en ComosDB?
El particionamiento horizontal en Azure Cosmos DB funciona dividiendo los datos de un contenedor en varias particiones de recursos, que son administrados de forma transparente por el sistema. Cada partición se organiza según una partition-key definida por el cliente y sirve para representar una unidad de alta disponibilidad, consistencia y escalabilidad.  
Aplciando este mecanismo se consigue que Azure Cosmos DB distribuya y escale el rendimiento elásticamente según los patrones de tráfico de las aplicaciones y las distintas regiones geográficas, sin afectar la disponibilidad, consistencia, latencia ni rendimiento.  
El sistema gestiona automáticamente estas particiones para mantener el nivel de rendimiento de un contenedor determinado usando una currency unit llamada Request Unit or RU y garantiza que los cambios en la capacidad estén disponibles en todas las regiones en pocos segundos  
### 2. ¿Comente el modelo de consistencia de CosmosDB?  
El modelo de consistencia de Azure Cosmos DB se basa en un diseño flexible y bien definido que permite a los desarrolladores escoger entre distintos niveles de consistencia, equilibrando rendimiento, latencia y disponibilidad según las necesidades de la aplicación.  
Por su diseño de gobernanza de recursos y al uso del lenguaje formal TLA+, Cosmos DB ofrece garantías de consistencia demostrables y un modelo de programación intuitivo y confiable para aplicaciones distribuidas globalmente.  También, es el único sistema de base de datos distribuido globalmente que implementa y expone a los desarrolladores los modelos de obsolescencia limitada, sesión y prefijo consistente, con semánticas claras y respaldo de Acuerdos de Nivel de Servicio (SLA) que aseguran el equilibrio entre rendimiento, consistencia y disponibilidad.  
### 3. ¿Comente como los objetivos de diseño de CosmosDB afectan la creación de aplicaciones?  
Los objetivos de diseño de Azure Cosmos DB buscan ofrecer un sistema flexible, consistente y altamente disponible, y esto ayuda o influye en la programación de aplicaciones.  Su arquitectura, basada en modelos de consistencia bien definidos con TLA+, garantiza baja latencia, durabilidad y alta disponibilidad, permitiendo construir aplicaciones distribuidas correctas y confiables en entornos globales y multiinquilino. Además, su motor de base de datos optimizado para escritura, independiente del esquema y con indexación automática, facilita el manejo de grandes volúmenes de datos manteniendo el rendimiento.  
El uso del modelo de datos ARS permite a Cosmos DB traducir y proyectar muy bien múltiples modelos y APIs, lo que da a los desarrolladores la libertad de usar APIs familiares mientras aprovechan todas las ventajas de un sistema distribuido globalmente, seguro y totalmente administrado.
