Comente 5 factores que afectan el rendimiento de las bases de datos: 

- la optimización de las consultas, consultas bien optimizadas hacen que la base de datos rinda mejor.  
- la atomicidad.  
- El plan de ejecución que se tenga a dentro de la propia base de datos afecta el rendimiento.  
- Los algoritmos propios de las bases de datos para manejar en  la memoria caché.  

¿Considera que afectan de igual forma a las Bases de Datos NoSQL y SQL? 

No, por los esquemas y la respectiva libertad ambos tipos de bases de datos, desde mi punto de vista, son afectadas de manera diferente por estos factores, por ejemplo en tema de optimizar consultas, las SQL al ser relacionales utilizan queries muy distintos a NoSQL.
