### 1. ¿Cómo funciona la arquitectura de Spanner?
La arquitectura de Spanner funciona combinando la replicación de datos en varios centros de datos con un sistema de tiempo global muy preciso llamado TrueTime. Spanner está diseñado para que las aplicaciones sigan funcionando cuando fallan o en caso de un desastre natural.  Los datos se replican en diferentes ubicaciones, ya sea dentro de una misma región o en distintos continentes. Spanner ofrece una base de datos multiversión y semirelacional, donde los datos se guardan en tablas con esquema y cada versión tiene una marca de tiempo automática.  Permite ajustar cómo y dónde se replican los datos.  Las aplicaciones pueden decidir cuántas copias mantener, en qué centros de datos, qué tan lejos de los usuarios estarán.  Spanner garantiza consistencia externa que hace que las transacciones se comportan como si ocurrieran una tras otra, gracias al TrueTime. para mantener una precisión temporal muy alta.  

### 2. ¿Cómo multi versionamiento en Spnnaer?
El multiversionamiento en Spanner se logra porque a diferencia de Bigtable, Spanner asigna marcas de tiempo a los datos. Esta característica permite que Spanner funcione como una base de datos multiversión y no solo como un simple almacén key-value.  Cada conjunto de datos, llamado tablet, guarda su estado en archivos con estructura de árbol B y en un registro de escritura anticipada dentro del sistema de archivos distribuido Colossus. Estas marcas hacen que Spanner pueda mantener diferentes versiones de los datos según el momento en que fueron escritos, lo que facilita lecturas consistentes de versiones anteriores mientras se siguen realizando nuevas escrituras. Tambien, todas las replicas pueden mantenr el mismo estado usando protocolo Paxos que coordina escrituras entre replicas y permite consistencia en el sistema. 

  
### 3. ¿En qué consiste el TRUETIME?
TrueTime es el sistema que usa Spanner para saber la hora con gran precisión y manejar correctamente el orden de las transacciones en todo el mundo.  TrueTime representa explícitamente el tiempo como un TTinterval, que es un intervalo con incertidumbre temporal acotada, a diferencia de las interfaces de tiempo estándar que no proporcionan a los clientes ninguna noción de incertidumbre. Los extremos de un TTinterval son de tipo TTstamp.  
TrueTime utiliza como referencia temporal el GPS y los relojes atómicos. Emplea estos dos sistemas de referencia debido a sus diferentes modos de fallo. Las vulnerabilidades del GPS incluyen fallos en la antena y el receptor, interferencias de radio locales, fallos correlacionados (como el manejo incorrecto de los segundos intercalares y la suplantación de identidad) e interrupciones del sistema GPS.
