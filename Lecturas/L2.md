#### 1. Explique los desafíos que se enfrentan en la construcción de sistemas distribuidos que requieren baja latencia (de acuerdo con la lectura)
<ins>_Slow processing queries_<ins>  
  
Como una base de datos en disco debe leer todo la infromacion desde almacenamiento físico, la velocidad a la hora de que el disco quiere recuperar la información por ejemplo cuando quiere hacer alguna consulta el motor de la base de datos tiene que buscar toda la información, más los tiempos de procesamiento que se sumen  antes de devolverlos hace que se aumenten los tiempos de respuesta.  
  
<ins>_Escalabilidad costosa_<ins>  
  
Escalar para una gran cantidad de lecturas puede ser costoso independientemente de si es una base de datos NoSQL basada en disco o en una base de datos relacional.  Además, algunas veces para escalar un sistema se puede requerir varias réplicas de lectura de la base de datos para igualar la capacidad de un solo nodo de caché en memoria en términos de solicitudes por segundo y esto solo implica costos adicionales.  

<ins>_Acceso a los datos_<ins>  
  
Las bases de datos basadas en alamcenamiento en disco son buenas para modelar relaciones pero no son buenas para acceder a los datos y esto hace que acceder a los datos se necesite una estructura o vista específica para simplificar este proceso y aumentar rendimiento.
